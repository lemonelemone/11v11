# NitroClash 11v11 Frankfurt v0.1.40

- Added rapid double-number quick chat for keys 0–9.
- Pressing `11` quickly is equivalent to `G1`; `00` is equivalent to `G0`, and so on.
- The 400 ms double-press window ignores held-key auto-repeat.
- Both input methods use the admin-selected custom/default quick-chat set shared by the arena.
- Changed the default match length to 10 minutes (600 seconds).
- Extended both admin timer inputs and server validation to 20 minutes (1,200 seconds), fixing values above the old input ceiling not applying.
- All v0.1.39 replay, smoothing, chat, viewer, admin, inactivity, braking, and gameplay changes remain intact.
