NITROCLASH 11v11 — FRANKFURT v0.1.35

PLAYER INSTALL / UPDATE
1. Replace the old Tampermonkey userscript with nitroclash-local-11v11.user.js.
2. Disable older NitroClash 11v11 userscripts.
3. Fully reload https://nitroclash.io/.
4. Use the NITROCLASH 11v11 panel and choose Join 11v11 or Spectate.

The Frankfurt connection is built in. Players do not need to enter or see a
server address. The v0.1.35 userscript requires the v0.1.35 Frankfurt server
(protocol 30).

CONTROLS
- Move: WASD, arrow keys or mouse steering
- Boost: left mouse
- Brake: right mouse, Space or Shift
- Public chat: T or Enter
- Team chat: Y
- Quick chat: G, then 1–9
- Scoreboard: hold Tab
- Camera mode: C
- Follow-camera zoom: mouse wheel (minimum 0.40x)
- Minimap: M

V0.1.35
- Production-labelled Frankfurt client with no testing label.
- The server address is fixed internally and is not displayed in the top-right
  panel, the scoreboard or connection-error messages.
- Host Admin panel includes Meow ON/OFF and the Custom/Default quick-chat slider.
- Mouse controls continue through the Admin panel, focused password fields and
  the fullscreen cat overlay.
- Lightweight team-coloured goal explosion.
- Public gameplay inactivity kick is 18 seconds and removes the player for
  everyone before closing their connection.
- 60 Hz authoritative physics, 120 Hz input and timestamped buffered rendering.
- Original pitch dimensions and artwork, penalties and six-second goal replays.

SERVER OWNER
- Deploy this folder's server.mjs and package.json to the Frankfurt service.
- Use Node 24.
- Start command: npm start
- The service must expose secure WebSockets through HTTPS/WSS.
- Do not mix this protocol-30 server with an older userscript.

Nothing in this ZIP deploys or uploads itself.
